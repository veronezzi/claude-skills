# Preparação para entrevista

## Tipos de pergunta

- Comportamentais (STAR): "Conte sobre uma vez que..."
- Técnicas: problemas, system design, coding.
- Situacionais: "O que você faria se..."
- Cultura/fit: motivação, valores.

## Método STAR

- Situation: contexto.
- Task: o que precisava ser feito.
- Action: o que você fez (foco em você).
- Result: resultado mensurável.

## Como gerar perguntas

Com base no cargo + job description, gere 10-15 perguntas prováveis. Para cada:
- Pergunta.
- O que o entrevistador avalia.
- Resposta STAR sugerida usando a experiência real do usuário.
- Red flags a evitar.

## Mock interview

Simule com personas: recrutador de RH, hiring manager, entrevistador técnico. Dê feedback após cada resposta: clareza, estrutura, métricas, tom.

## Regras

- Nunca invente experiência. Use só o que o usuário informou.
- Adapte à senioridade: júnior = potencial; sênior = impacto.
