# Post-interview coaching

## Diagnóstico após rejeição

Classifique a causa em 3 categorias:

1. Skill gap: faltou conhecimento/técnica. Ação: estudar + projeto.
2. Signal gap: tinha a skill mas não comunicou. Ação: treinar STAR + métricas.
3. Fit issue: perfil não combina com a cultura/equipe. Ação: reavaliar alvo.

## Perguntas ao usuário

- "Em qual etapa você parou?"
- "Que feedback recebeu (se houver)?"
- "O que sentiu que foi mal?"
- "Houve pergunta que travou?"

## Saída

- Diagnóstico provável.
- 3 ações concretas.
- Pergunta para pedir feedback ao recrutador (template de email).
- Plano de melhoria para próxima candidatura.
