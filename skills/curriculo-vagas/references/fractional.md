# Carreiras fracionárias / portfolio

## Quando usar

Para quem constrói carreira como consultor, advisor, fractional executive ou board member.

## Elementos

- Rate setting: diária, por projeto, retainer. Pesquise mercado.
- Estrutura legal: BR (MEI/Simples), US (LLC/S-Corp), UK (IR35).
- Aquisição de clientes: rede, conteúdo, cold outreach, plataformas.
- Posicionamento no LinkedIn: headline com "Fractional [Cargo]", about com ofertas.
- Portfolio de engajamentos: lista com resultados.

## LinkedIn para fracionário

- Headline: "Fractional CTO | Ajudando startups a escalar engenharia"
- About: quem você ajuda, como, resultados, como contatar.
- Featured: cases, artigos, site.

## Regras

- Defina nicho claro. "Faço de tudo" não vende.
- Colete depoimentos de cada cliente.
- Mantenha 2-3 engajamentos simultâneos para diversificar risco.
